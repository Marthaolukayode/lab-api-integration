# Multi-Provider News Summarizer

## What the Project Does

The Multi-Provider News Summarizer is a Python application that automatically fetches technology news articles and processes them using two different AI providers.

The workflow is:

**NewsAPI → OpenAI → Cohere → Structured Output**

- **NewsAPI** retrieves current technology news articles.
- **OpenAI** generates a short 2–3 sentence summary of each article.
- **Cohere** analyzes the sentiment of the article as Positive, Negative, or Neutral.
- The results are combined into a structured output containing the article title, summary, and sentiment.

The project demonstrates how multiple AI providers can be integrated into one workflow while reducing dependency on a single provider.

## Setup

### 1. Install the required packages

From the project directory, run:

```bash
pip install -r requirements.txt
```

### 2. Configure environment variables

Create a `.env` file in the project folder:

```text
OPENAI_API_KEY=your_openai_api_key
COHERE_API_KEY=your_cohere_api_key
NEWS_API_KEY=your_news_api_key

ENVIRONMENT=development
MAX_RETRIES=3
REQUEST_TIMEOUT=30
DAILY_BUDGET=5.00
```

Never commit the `.env` file to GitHub.

The `.gitignore` file should contain:

```text
.env
.env.*
__pycache__/
*.pyc
*.pyo
*.log
.pytest_cache/
```

## How to Run

### Check the configuration

```bash
python config.py
```

This verifies that the required API keys are available.

### Test NewsAPI

```bash
python news_api.py
```

This fetches and displays technology news articles.

### Test the AI providers

```bash
python llm_providers.py
```

This tests the OpenAI and Cohere integrations.

### Run the news summarizer

```bash
python summarizer.py
```

The application fetches news articles, summarizes them with OpenAI, analyzes their sentiment with Cohere, and displays the results.

### Run the tests

```bash
pytest test_summarizer.py -v
```

## Cost Analysis

The application uses external APIs, so processing articles may generate API costs.

The main cost sources are:

- **OpenAI:** cost depends on the selected model and the number of input and output tokens.
- **Cohere:** cost depends on the selected model and usage.
- **NewsAPI:** usage depends on the API plan and request limits.

The project configuration includes:

```text
DAILY_BUDGET=5.00
```

This represents the intended daily budget setting for the application. Actual API usage and costs should be checked against the providers' current pricing and usage dashboards.

Processing fewer articles and keeping prompts and generated summaries concise can help reduce token usage and overall API cost.
